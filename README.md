# Catatan Keuangan Mini

Aplikasi React untuk mencatat pemasukan dan pengeluaran. Saldo dihitung dari transaksi, dan data disimpan otomatis di `localStorage` browser.

## Menjalankan aplikasi

```bash
npm install
npm run dev
```

Form transaksi mencakup keterangan, nominal, dan jenis transaksi. Setiap transaksi dapat dihapus dari daftar.
